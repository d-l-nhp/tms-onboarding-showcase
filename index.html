Profit Sharing

How Splits Process & Settle
⏱ Split processing
After a split order is submitted it is Pending. The system runs split processing daily at 23:00 Beijing time; the status then becomes Success or Failed.
💰 Funds settlement
Split processing and fund settlement are two separate things. Split funds settle to the target merchant account in T+2 business days.
⚠️ Merchant responsibility
Split rules are configured by the merchant. NihaoPay is not liable for losses caused by mis-configuration (failed splits or wrong amounts not due to a platform bug).

Split Mode Configuration

Merchant-defined split modes — system auto-applies based on transaction field matching

How Split Modes Work

① Define
Create a split mode with a unique key (e.g. website_split) and configure its rules.
② Include in API
Pass split_mode in your transaction API request to trigger auto-matching.
③ Auto split + callback
NihaoPay runs T+2 batch split and POSTs result to your callback URL.
Merchant Liability Disclaimer
All split modes are configured by you. If a split fails due to misconfiguration — not a platform bug — NihaoPay bears no financial liability. Test all modes before enabling in production.
